bezel.fit · v1 · stable

Frame your simulator screenshots.

Drop a screenshot from Xcode's iOS simulator or Android Studio's Android emulator, get back a framed PNG on the background of your choice. One POST request. No SDK, no scaling, no signup.

Try it ↓ See examples ↓

02 — Reference

      
Options

      

        Every option the API accepts, with grammar, defaults, and a one-liner curl.

Device

          

            Picks the device frame and the expected screenshot dimensions.
            The PNG body must match the viewport exactly. Anything
            else gets rejected with dimension_mismatch.

finish · query · optional

          
Color variant

          

            Picks a finish other than the device default. iPhone-only — Pixel
            frames don't have color variants. Using a finish a device doesn't
            have returns
            unsupported_finish
            with the available list inline.
          

          

            

              
                

                  device
                  default
                  finishes
                

              
              
                
iphone-17blackblack, white, mist-blue, sage, lavender

                
iphone-17-prosilversilver, cosmic-orange, deep-blue

                
iphone-17-pro-maxsilversilver, cosmic-orange, deep-blue

                
iphone-airspace-blackspace-black, cloud-white, light-gold, sky-blue

              
            

          

          
# cosmic-orange iPhone 17 Pro
curl -X POST 'https://bezel.fit/v1/devices/iphone-17-pro/frame?finish=cosmic-orange' \
  --data-binary @screen.png --fail -o framed.png

        


        
        

          
background · query · optional

          
Canvas fill

          

            Without this, output is the frame's native size with a transparent
            canvas. Setting any non-transparent value enables canvas mode and
            unlocks preset /
            padding /
            cornerRadius.
          

          
# grammar
transparent
color:<hex>                       # #rgb · #rgba · #rrggbb · #rrggbbaa
linear:<hexA>,<hexB>[,<deg>deg]    # default 180deg (top→bottom)

          
# story-sized canvas with a sunset gradient
curl -X POST 'https://bezel.fit/v1/devices/iphone-17-pro/frame?preset=ig-story&background=linear:%23ff7a18,%23af002d,135deg' \
  --data-binary @screen.png --fail -o framed.png

        


        
        

          
preset · query · optional

          
Output canvas size

          

            Centers the frame on a fixed-size canvas with ~10% breathing room.
            The frame is downscaled with premultiplied-alpha box filtering, so
            rounded corners stay clean against the background.
            Requires a non-transparent background.
          

          

            

              
                

                  name
                  pixels
                  use
                

              
              
                
ig-square1080 × 1080Instagram feed (1:1)

                
ig-portrait1080 × 1350Instagram feed (4:5)

                
ig-story1080 × 1920Story / TikTok (9:16)

                
x-landscape1600 × 900X / Twitter (16:9)

                
linkedin-share1200 × 627LinkedIn shared image

                
og-image1200 × 630Open Graph / blog hero

                
app-store1320 × 2868Apple App Store (6.9" iPhone)

                
play-store1080 × 1920Google Play Store phone (9:16)

              
            

          

          
# 1080×1080 Instagram square on a dark fill
curl -X POST 'https://bezel.fit/v1/devices/pixel-10/frame?preset=ig-square&background=color:%230d1117' \
  --data-binary @screen.png --fail -o framed.png

        


        
        

          
cornerRadius · query · optional

          
Canvas corners

          

            Rounds the canvas corners with a 1-pixel feather for clean
            anti-aliasing. Each tier is a fraction of the shorter canvas axis,
            so the same tier scales sensibly across presets. No-op in
            transparent mode.
          

          

            

              
                

                  tier
                  fraction
                  @ 1080×1080
                

              
              
                
none00 px

                
sm0.0222 px

                
md0.0443 px

                
lg0.0886 px

              
            

          

          
# rounded canvas corners on an OG image
curl -X POST 'https://bezel.fit/v1/devices/iphone-17-pro-max/frame?preset=og-image&background=color:%230d1117&cornerRadius=md' \
  --data-binary @screen.png --fail -o framed.png

        


        
        

          
padding · query · optional

          
Breathing room

          

            Adds space on each side between the device and the canvas edges.
            Each tier is a fraction of the shorter canvas axis. Omit it for
            the defaults (10% inside a preset, 0% in background-only mode);
            padding=none
            packs the device flush against the edges. No-op in transparent
            mode.
          

          

            

              
                

                  tier
                  fraction
                  @ 1080×1080
                

              
              
                
none00 px

                
sm0.0554 px

                
md0.10108 px

                
lg0.15162 px

                
xl0.20216 px

              
            

          

          
# pack the device flush against the preset edges
curl -X POST 'https://bezel.fit/v1/devices/iphone-17-pro/frame?preset=ig-square&background=color:%230d1117&padding=none' \
  --data-binary @screen.png --fail -o framed.png

        


        
        

          
body · request · required

          
Input PNG & limits

          
    
            
  • Use the screenshot straight out of the simulator or emulator. The viewport sizes match what those tools output.
    • 
            
  • Body is raw PNG bytes: 8-bit RGB or RGBA, no palette / 16-bit / interlaced.
    • 
            
  • Width × height must equal the device viewport exactly. No scaling.
    • 
            
  • Max payload 8 MiB.
    • 
            
  • Rate limit: 3 requests / 60 s per source IP.
    • 
            
  • 4xx errors return JSON with { error, message, … }.
              Codes: unknown_device,
              unsupported_finish,
              not_png,
              unsupported_png_format,
              corrupt_png,
              dimension_mismatch,
              invalid_background,
              invalid_preset,
              invalid_corner_radius,
              invalid_padding,
              payload_too_large,
              rate_limited.
